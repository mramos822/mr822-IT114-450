\## Project Name: \*\*Multiplayer Rock Paper Scissors Game\*\*

\## Project Summary: A Java-based client-server multiplayer Rock Paper
Scissors game that supports Classic and Extended modes (RPS-5). Features
include room management, real-time UI updates, ready-check system, game
events log, away/spectator modes, and a post-game countdown. Built using
Java Swing for the UI and sockets for client-server communication.
